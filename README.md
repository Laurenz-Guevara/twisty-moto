## Getting Started

If you would like to build this app locally for yourself just follow the instructions below.

### Installation

1. Clone the repo

    ```bash
    git clone git@github.com:Laurenz-Guevara/twisty-moto.git
    ```

2. Install Packages

    ```bash
    npm install
    ```

3. Start the App

    ```bash
    npm run dev
    ```
